# Week 7 – Advanced Backend Technologies: Beyond REST APIs 🚀

> **Optional to Learn**

Welcome to Week 7!

Congratulations on completing the core MERN stack and getting familiar with deployment and DevOps basics.

This week, we'll explore technologies commonly used in modern backend systems. These tools are widely adopted in startups and large-scale applications to improve performance, developer experience, scalability, and real-time communication.

Don't worry if some of these concepts feel advanced. The goal this week is to understand where each technology fits and gain enough hands-on experience to start using them in your own projects.

- Caching
- Sessions
