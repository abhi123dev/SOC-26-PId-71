# Week 6 Assignment – Final Project (Stage 1) 🚀

Welcome to Week 6!

This week marks the beginning of the implementation phase of your **Final Project**.

Last week, you finalized your project idea, identified the problem statement, and planned the features. Now it's time to start building.

While this week's learning resources cover Linux, Docker, CI/CD, and Deployment, **those concepts are optional to implement this week**. Your primary focus should be completing **Stage 1** of your Final Project.

---

## 🎯 Mandatory Task – Final Project (Stage 1)

Implement the core foundation of your project.

By the end of this week, your project should have the following:

### ✅ Project Setup

* Create the complete project structure
* Set up the frontend and backend
* Configure the database
* Configure environment variables
* Push the initial project to GitHub

---

### ✅ Database & Backend

* Design and create all required database models/schemas
* Connect the backend to the database
* Set up API routes for the core modules
* Verify the backend runs successfully

---

### ✅ Frontend Setup

* Set up the frontend project
* Create the basic folder structure
* Configure routing (if applicable)
* Build the basic UI layout/pages

---

### ✅ Core Functionality

Implement the first working version of your project's primary feature.

Examples:

* Authentication (Login/Register)
* CRUD for your main entity
* Dashboard layout
* Notes management
* Blog creation
* Product listing

Choose the feature that forms the foundation of your application.

---

### ✅ GitHub Progress

Your repository should show regular commits throughout the week instead of a single large upload at the end.
